# java-lotto-precourse

## 요구사항 나열

- 로또 구입 금액을 입력받는다.
  - 로또 구입 금액은 양수이다.
  - 로또 구입 금액은 1,000원 단위로 입력받는다.
  - 로또 구입 금액이 1,000원으로 나누어 떨어지지 않으면 예외 처리한다.
  - 단, 0원을 입력 시 예외처리한다.
- 로또를 구입한다.
  - 구매자는 로또 구입 개수만큼 구매한다.
  - 로또 판매점은 판매 개수만큼 로또를 만들어 판매한다.
    - 로또 번호는 6개이다.
    - 로또 번호간의 중복은 없어야한다.
- 구입한 로또 번호들을 출력한다.
  - 오름차순으로 출력한다.
- 당첨 번호를 입력받는다.
  - 당첨 번호는 6개이다.
  - 당첨 번호간의 중복은 없어야한다.
- 보너스 번호를 입력받는다.
  - 보너스 번호는 1개이다.
  - 당첨 번호와 중복은 없어야한다.
- 구매자의 로또가 당첨되었는 지 확인한다.
  - 구매자의 로또 번호와 당첨번호+보너스 번호를 비교한다.
- 당첨 내역(통계)을 출력한다.
  - 당첨은 3개~6개 일치로 구성되어있다.
  - 특히 5개 일치는 (일반 번호 5개 or 일반 번호4개 + 보너스 번호 1개)로 구분된다.
  - 당첨 통계는 X개 일치, 상금액, 개수를 출력한다.
- 수익률을 출력한다.
  - 누적 상금액과 로또 구입 금액으로 수익률을 측정한다.

## 구현 기능 목록

1. InputReader
- [입력] 사용자로부터 돈을 입력받는다.

2. Money
- [검증] 문자열 값을 정수형으로 변환할 때 검증한다.
- [검증] 정수가 음수인 지 검증한다.
- [검증] 정수가 0인 지 검증한다.
- [변환] 내가 가진돈을 구매 수량으로 변환한다.
- [계산] 내가 투자한 Money 대비 수익금을 계산한다.

3. Number
- [검증] 문자열 값을 정수형으로 변환할 때 검증한다.
- [검증] 1과 45사이의 값인지 확인한다.

4. Lotto
- [타입] 주어진 List<Integer>대신 List<Number>타입을 사용한다.
- [출력] 출력할 때, 오름차순 정렬하여 출력한다.

5. LottoBundle
- [타입] List<Lotto>를 가진다.

6. Customer
- [타입] Money를 가진다.
- [타입] LottoBundle을 가진다.
- [구매] LottoStore로부터 LottoBundle을 구매한다.

7. LottoStore
- [생성] 수량 만큼 로또를 생성한다.
- [판매] 돈을 받아, 로또를 판매한다.

8. WinningLotto
- [타입] 일반 번호 모음인 Lotto를 가진다.
- [타입] 보너스 번호인 Number타입의 bonusNumber를 가진다.
- [검증] 보너스 번호가 일반 번호모음와 중복되는 지 검증한다.
- [비교] 구매자의 로또 번호와 당첨 번호를 비교한다.

9. LottoRank
- [상수] 로또 당첨 순위를 가진다.
- [변환] 일치하는 당첨번호개수와 보너스 번호개수를 로또당첨순위로 변환한다.

10. LottoResult
- [타입] 전체적인 로또 당첨 결과를 가진다.
- [계산] 로또 당첨으로 얻은 전체 수익금을 계산한다.

11. outputWriter
- [출력] 주어진 형식에 따라서 출력한다.
  - [출력] 구입금액 요청 메세지를 형식에 따라 출력한다.
  - [출력] 예외 메세지를 출력한다.
