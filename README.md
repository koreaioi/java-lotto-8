# java-lotto-precourse

## 요구사항 나열

- 로또 구입 금액을 입력받는다.
  - 로또 구입 금액은 양수이다.
  - 로또 구입 금액은 1,000원 단위로 입력받는다.
  - 로또 구입 금액이 1,000원으로 나누어 떨어지지 않으면 예외 처리한다.
  - 단, 0원을 입력 시 예외처리한다.
- 로또를 구입한다.
  - 구매자는 로또 구입 개수만큼 구매한다.
  - 로또 판매점은 판매 개수만큼 로또를 만들어 판매한다.
    - 로또 번호는 6개이다.
    - 로또 번호간의 중복은 없어야한다.
- 구입한 로또 번호들을 출력한다.
  - 오름차순으로 출력한다.
- 당첨 번호를 입력받는다.
  - 당첨 번호는 6개이다.
  - 당첨 번호간의 중복은 없어야한다.
- 보너스 번호를 입력받는다.
  - 보너스 번호는 1개이다.
  - 당첨 번호와 중복은 없어야한다.
- 구매자의 로또가 당첨되었는 지 확인한다.
  - 구매자의 로또 번호와 당첨번호+보너스 번호를 비교한다.
- 당첨 내역(통계)을 출력한다.
  - 당첨은 3개~6개 일치로 구성되어있다.
  - 특히 5개 일치는 (일반 번호 5개 or 일반 번호4개 + 보너스 번호 1개)로 구분된다.
  - 당첨 통계는 X개 일치, 상금액, 개수를 출력한다.
- 수익률을 출력한다.
  - 누적 상금액과 로또 구입 금액으로 수익률을 측정한다.
